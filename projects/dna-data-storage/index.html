DNA data storage

writing and reading digital data in DNA on a single electrochemical device

DNA is an appealing medium for archival storage. It is dense, it lasts, and it copies itself. What holds it back is the apparatus: writing a file and reading it back normally means two separate instruments and a lot of manual transfer in between.

My doctoral work approached that gap from the hardware side. We built a system that both synthesizes and sequences DNA electrochemically on one gold electrode, so a file can be written and read without leaving the device (Xu et al., 2021). Because synthesizing every strand from scratch is wasteful, we then treated pre-made DNA blocks as movable type and assembled them into new messages instead (Xu et al., 2023).

We also stepped back to ask what actually limits the reliability of such a pipeline, and surveyed where errors enter a synthetic-DNA storage system end to end (Xu et al., 2021).

Work from the same group scaled the electrode array and tested alternative substrates for on-chip synthesis (Feng et al., 2026; Gao et al., 2025; Feng et al., 2024).
